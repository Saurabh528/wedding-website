## विशेषताएं

- ✨ **वाराणसी थीम**: पारंपरिक भारतीय रंग और सांस्कृतिक तत्व
- 📱 **पूर्ण रूप से रेस्पॉन्सिव**: सभी उपकरणों पर सही तरीके से काम करता है

- 📅 **इवेंट टाइमलाइन**: सभी विवाह कार्यक्रमों की जानकारी
- 📝 **RSVP फॉर्म**: अतिथि पुष्टि के लिए
- 🎨 **सुंदर एनिमेशन**: स्मूथ स्क्रॉल और फेड-इन इफेक्ट्स

## फाइल संरचना

```
website_wedding/
├── index.html          # मुख्य HTML फाइल
├── styles.css          # CSS स्टाइलिंग
├── script.js           # JavaScript इंटरैक्टिविटी
├── photos/             # फोटो फोल्डर
│   └── [wedding photos]
└── event_details.pdf   # इवेंट विवरण
```

## उपयोग

1. सभी फाइलें एक ही फोल्डर में रखें
2. `index.html` को ब्राउज़र में खोलें
3. या लोकल सर्वर चलाएं:
   ```bash
   # Python 3
   python3 -m http.server 8000
   
   # Node.js (http-server)
   npx http-server
   ```

## कस्टमाइजेशन

### रंग बदलना
`styles.css` में `:root` वेरिएबल्स को संपादित करें:
- `--saffron`: केसरिया रंग
- `--maroon`: मैरून रंग
- `--gold`: सोने का रंग

### फोटो जोड़ना/हटाना
`script.js` में `photoFiles` array को अपडेट करें।

### RSVP फॉर्म
वर्तमान में RSVP फॉर्म कंसोल में डेटा प्रिंट करता है। वास्तविक सबमिशन के लिए:
- EmailJS, Formspree, या अपना बैकएंड इंटीग्रेट करें
- `script.js` में RSVP form handler को अपडेट करें
