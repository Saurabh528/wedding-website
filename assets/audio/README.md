# Audio Files

Place your 40-second wedding music clip here.

**File name:** `wedding-music.mp3` (or `.ogg` format)

The audio will:
- Automatically play when the website loads (with fade in)
- Loop continuously
- Fade out 2 seconds before the end of each loop
- Fade in at the start of each loop
- Play at 30% volume

**Note:** Due to browser autoplay policies, the music may require a user interaction (click/tap) to start playing on some browsers.
